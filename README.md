# Assignment 1 — Web Development & Layout Basics

A web development repository containing practical HTML5 and CSS tasks covering page layout, styling, forms, and responsive design concepts.

---

## Tasks Overview

* **Task 1: Profile Card** — Personal profile card featuring background details, a skills list (`<ul>`), a favorite games list (`<ol>`), and social links.
* **Task 2: Multi-Column Layout** — Classic two-column web layout featuring a sidebar (`#menu`) and main content area (`#content`).
* **Task 3: Biography Page** — Split-screen biographical page dedicated to Alan Turing (text on the left, image on the right) with Roman numeral ordered lists (`<ol type="I">`).
* **Task 4: OS Grade List & Form** — Operating Systems grade table utilizing column spanning (`colspan="3"`), alternate row shading (`:nth-child(even)`), and an interactive HTML form.
* **Task 5: Midterm Wireframe** — Midterm page layout structure and link navigation.
